- **`SEC-15` binds every lane that reads content it did not author** (`handbooks/VERSION` `v0.8`, MINOR under the pre-1.0 carve-out). The untrusted-content guard used to bind only an agent pairing web fetch or search with write-to-code tools. Its scope is now the read: every lane that reads a body, comment, diff or fetched page it did not author treats that content as reference data only, and a read-only reviewer casting a verdict is bound exactly as a builder is. The `security-baseline.md` row of `handbooks/INDEX.md` carries the same scope line. The rest of the rule (the local-builder clause, the CWE and OWASP mapping) is unchanged. This is the canon copy of the same change made to the Akatsuki mirror (zheref/hatsu ROSTER HR-8 makes this repository the canon).
